TokenText-Converter 

A simple Python project that converts text into token IDs and decodes token IDs back into readable text using the tiktoken library.

Features
Convert text into token IDs.
Convert token IDs back into text.
Simple menu-based interface.
Requirements
Python 3
tiktoken
Installation
bash
pip install tiktoken

Usage

Run the program:

bash
python main.py


Choose an option:

Text to Token IDs
Token IDs to Text

Note: Use the same tokenizer encoding (cl100k_base) for encoding and decoding.
